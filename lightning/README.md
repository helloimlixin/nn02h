# Tutorial on PyTorch Lightning

This is a quick tutorial on PyTorch Lightning, a lightweight PyTorch wrapper that helps you organize your PyTorch code
and makes it more readable and maintainable. The major reason for this tutorial is to be able to quickly get started
with PyTorch Lightning and especially its multi-GPU capabilities.

To get started, you need to install PyTorch Lightning. You can do this using pip:

```bash
pip install pytorch-lightning
```

This tutorial major follows the YouTube tutorial by Aladdin Persson on PyTorch Lightning. You can find the tutorial [here](https://www.youtube.com/watch?v=QHww1JH7IDU).
