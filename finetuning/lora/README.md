# LoRA From Scratch

Tutorial on how to train a LoRA model from scratch. This tutorial is based on:
- Paper: [LoRA: Low-Rank Adaptation of Large Language Models](https://arxiv.org/abs/2110.05224) by Yi Tay, Mostafa Dehghani, and Dara Bahri.
- Blogpost by Lightning AI: [LoRA From Scratch](https://lightning.ai/docs/overview/finetune-models/llm-low-rank-adaption-of-large-language-models-lora?tab=overview).
